## 🎯 About Me

> **Senior GIS Engineer and Full Stack Developer** with 6+ years building geospatial data pipelines, satellite remote sensing systems, and enterprise-scale web applications.

I specialize at the intersection of **spatial data engineering** and **full-stack development** — turning raw satellite imagery, PostGIS databases, and complex geospatial workflows into production systems used by thousands of users. Currently pursuing **MS Data Science** at PUCIT, University of Punjab, with a thesis on spatiotemporal GNN for crop pest prediction using satellite remote sensing.

## 🚀 Featured Projects

### 🌍 Agricultural GIS Platform
**PostGIS · Angular 19 · Mapbox GL JS · Golang · Python · Sentinel-2 · GEE**

Enterprise GIS dashboard serving **2,400+ production users** with **15M+ database rows**. Built geospatial data pipelines for satellite-based crop monitoring — NDVI analysis, Sentinel-2 imagery ingestion via Google Earth Engine, partitioned PostGIS `shapes` table with custom tileset management system (GeoJSON → ogr2ogr → Mapbox Tilesets API). Cane outflow feature with Bezier arc flows on Mapbox GL JS proportional to tonnage volume.

`15M+ rows` · `2,400+ users` · `AWS ap-southeast-1 RDS` · `Multiple enterprise organizations`

---

### 🗺️ FAO Crop Pattern Planning Tool
**Angular 21 · FastAPI · PostGIS 3.4 · MapLibre GL JS · TiTiler · Docker · CMIP6**

Geospatial decision-support tool for water and crop scenario modeling across Punjab & Sindh provinces. 50-year climate projections using CMIP6 NetCDF data (SSP1-2.6 → SSP5-8.5). Scenario engine computes water demand vs supply (BCM) across 5 crop types. Ground truth validation with confusion matrix accuracy reporting. Raster serving via TiTiler (COG) for 30m-resolution crop maps.

`108 admin boundaries` · `50-year projections` · `WaPOR v3 ET data` · `GeoTIFF/GeoJSON export`

---

### 🏙️ Billboard SaaS Marketplace
**Next.js · PostGIS · Mapbox GL JS · Redis · Prisma**

B2B SaaS platform for programmatic billboard advertising with **400K+ billboard inventory** across 14 US states. Viewport-aware spatial clustering using `ST_ClusterDBSCAN`, vector tile rendering for performance, Redis-cached queries, AI-powered industry matching, and campaign workflow management.

`400K+ billboards` · `14 US states` · `AI industry matching` · `Vector tiles + Redis`

---

### 🤖 AI Call Center QA System
**React · HapiJS · FastAPI · TensorFlow · AWS Lambda SAM · Aurora PostgreSQL**

Multi-tenant AI soundboard assistant for enterprise call centers. AI listens to callers in real time and predicts which pre-recorded audio key to play next. Continuous retraining pipeline: Windows PCs → S3 → EventBridge → SQS → Lambda → TensorFlow model → deployed back to PCs. Built 9 internal Python libraries (pykombea).

`9 enterprise clients` · `3,035+ calls/day` · `28.6M DB rows` · `AWS Lambda pipeline`

---

### 🛒 ResellAI — AI Reselling OS
**Next.js 15 · FastAPI · AWS Bedrock · Claude Sonnet 4.5 · Aurora Serverless v2 · Lambda**

7-agent AI workflow on AWS Strands Agents SDK. Agents: Vision & Item ID (Claude Haiku/Sonnet), Pricing Intelligence (eBay sold comps + Apify), Listing Generation, Platform Publisher (eBay + Shopify), Sale Completion, Orchestrator. 7 MCP servers: DB, S3, Rekognition, eBay API, Shopify API, SES, Apify.

`7 AI agents` · `7 MCP servers` · `Saves $150-200/mo + 15 hrs/week` · `eBay + Shopify`

---

### 📞 Hotel Voice Bot
**Python · Pipecat 1.3.0 · Twilio · Whisper STT · Cartesia TTS · Silero VAD · FastAPI**

Real-time AI phone agent with **~1.2s end-to-end latency** via streaming pipeline — Groq Whisper STT (~400ms) → LLaMA 3.3 70B with function calling (~300ms) → Cartesia sonic-2 TTS streaming (~200ms). Multi-hotel architecture from single server: phone number → YAML config per hotel (rooms, pricing, personality). Handles bookings, reservations, inquiries, human transfer.

`~1.2s latency` · `Multi-hotel` · `Groq + Cartesia` · `Next.js dashboard`

---

### 🏠 Nearo — Student Housing Platform
**Next.js · Expo/React Native · PostgreSQL + PostGIS · Clerk · Prisma · Vercel**

Student accommodation and local discovery platform for Lahore. PostGIS `geography(Point,4326)` for spatial proximity queries. HMS (Hostel Management System) for owners. AI chat assistant, roommate matching, Expo push notifications.

`2,500+ hostels` · `81 universities` · `Web + Android APK` · `nearo.pk`

---

### 🌐 GeoScope-3D — 3D Geospatial Visualization
**React · CesiumJS v1.112.0 · Resium · Turf.js · TypeScript**

Full 3D geospatial platform with satellite imagery, terrain, 3D buildings, and street map layers. Drawing tools (circle, line, polygon) with measurement output. Drone mission planning: waypoints, grid survey modal, altitude profile chart. 5 React context providers (Scene, Layer, Measurement, Drone, Building). Built for a City of Surrey, BC bid (Moovmynt Technology Inc.).

`CesiumJS + Mapbox dual-view` · `Drone mission planning` · `Entity system + metadata dialogs`

---

### 🧭 Indoor Convention Wayfinding
**React · TypeScript · IMDF · SVG**

Multi-floor indoor navigation using Apple's Indoor Mapping Data Format (IMDF). Custom A* pathfinding with min-heap priority queue. Dynamic rerouting: 5m deviation threshold, 3-consecutive-reading confirmation. Turn-by-turn instructions computed from vector angles. IMDF hierarchy: Venue → Building → Level → Unit → Opening → Anchor.

`A* pathfinding` · `Multi-floor navigation` · `BLE/WiFi position smoothing`
